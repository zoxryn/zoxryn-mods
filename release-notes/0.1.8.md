# Zoxryn Mods v0.1.8

Phase 1.7 adds Collections and a dedicated Suits & Skins manager while preserving the existing application, database, mod scanner, backups and signed updater.

- Organize imported packages and discovered OpenIV containers using verified package/ownership/container relationships. Create and edit custom collections without duplicating mod ownership.
- Browse named suit declarations and clearly marked character-resource candidates in six categories, with search, sorting, grid/list layouts, expandable components and a details panel.
- Assign local PNG/JPEG/WebP previews or use explicit package artwork. Bounded thumbnails are stored outside GTA V and loaded lazily; missing artwork uses a named purple placeholder.
- Review reversible enable/disable for complete independently declared Zoxryn-owned standalone script/ASI outfit packages. Plans check ownership, dependencies, shared companions and backups and require explicit approval. Installation state does not equip an outfit in-game.
- Keep shared RPF/AddonPeds resources read-only when isolation or registration is unverified. No original RPF is edited and arbitrary character assets are not treated as complete identified suits.
- Migrate existing data to SQLite schema 3 with a retained pre-migration copy. Existing archives, settings, mod records, ownership, scans and backups remain in place.

See `ORGANIZATION.md` for the supported metadata format, safety checks and discovery limits. Arbitrary OpenIV/AddonPeds suit installation, registration editing, encrypted/nested RPF decoding and in-game equipping remain unsupported.

This release uses the established Tauri update signing identity. Windows Authenticode signing is separate and has not been configured.
