# Zoxryn Mods 0.1.7

- Connects the existing signed updater to the official zoxryn/zoxryn-mods GitHub Releases channel.
- Adds signed metadata expiry, stricter repository redirect checks and signed installer checksum validation.
- Shows the last update check and a useful status when no stable release has been published.
- Preserves approval before download, installation and restart, along with the established signing identity.
- Keeps existing mod records, imported archives, ownership, settings and retained backups in their existing data directory.

This is the one-time manual bootstrap for older installations. Future approved stable releases can be installed through Settings → Application updates. Application updates do not manage GTA V files.
